# CredoConnect public website

This directory contains the public, UI-only CredoConnect catalogue published at the Manus-hosted website.

The catalogue uses fictional Safaricom and Airtel data, SMS, and voice products for interface testing. Purchasing, M-Pesa, Vinnie airtime fulfilment, authentication, and database writes are intentionally disabled. Do not add provider credentials to this directory; use a deployment secret manager when live integrations are approved.

Run locally from this directory with:

```bash
npm install
npm start
```
